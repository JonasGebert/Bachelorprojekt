# R05 — Kernbruch/Kernzerfall macht Innenkontur unbrauchbar

## Beschreibung

Kernbruch/Kernzerfall macht Innenkontur unbrauchbar.

## Bewertung

| Kriterium | Wert | Skala |
|---|---|---|
| Schadenswahrscheinlichkeit | 2 | 1 = niedrig … 3 = hoch |
| Schadenshöhe | 2 | 1 = niedrig … 3 = hoch |
| Risikozahl (W x H) | 4 | Zone: **monitor** (ok < 3 ≤ monitor < 6 ≤ act) |

## Maßnahme

- **Maßnahme:** V-K1 früh durchführen; Kern Ø 14 mm robust auslegen; Rückfallebene Wasserglas-CO2-Kern
- **Typ:** praeventiv (praeventiv reduziert Wahrscheinlichkeit und/oder Höhe, korrektiv nur die Höhe)
- **Wirkung auf:** beide
